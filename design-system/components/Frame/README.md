# Frame

The edge alone, for pictures, avatars, canvases and sprites; pixel art inside it scales nearest-neighbour.

Markup: `<span class="nc-frame"><img src="…" width="96" alt="…"></span>` (an `img`, `canvas` or `video` child fills it). Edge `nc-quiet`; `--gold` for the podium, `--pink` for you, `--cyan` for the active one.

Do: size the picture in whole multiples of its pixel size.
