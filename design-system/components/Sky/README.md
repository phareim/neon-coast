# Sky

The scenery in plain CSS, for when there is no script: `.nc-sky`, `.nc-sun`, `.nc-horizon` and `.nc-crt`.

- `.nc-sky` — the dusk in eight hard bands, `nc-sky-0` at the top to `nc-sky-7`.
- `.nc-sun` — the striped half sun, `nc-sun-0` … `nc-sun-3` with bands of `nc-sky-5` (`--nc-sun-band`); set its width with `--nc-sun-size` (160 px).
- `.nc-horizon` — a cyan line with the sea under it (`--nc-horizon-height`, 48 px).
- `.nc-crt` — scanlines and a vignette laid over any element.
- `.nc-pixelated` — nearest-neighbour scaling for pixel-art images.

For the live, lit version use Scene.
