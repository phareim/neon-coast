# Kbd

A key cap: pixel letters on `nc-dusk` with an `nc-slate` edge and a thicker bottom.

Markup: `<kbd class="nc-kbd">Esc</kbd>` (inside `class="nc"`, any `<kbd>`). Use it in hints and help text: `<kbd>←</kbd><kbd>→</kbd> move · <kbd>Space</kbd> jump`. Write the key as it is printed on a keyboard; on touch screens say the gesture instead.
