# Dialog

What people in the world say: `nc-white` pixel letters with an `nc-plum` shadow in a box with an `nc-hot` edge.

Markup: `<div class="nc-dialog">…</div>`, or `<dialog class="nc-dialog">` opened with `showModal()` (it gets a dimmed backdrop and centres itself). Add `<span class="nc-more"></span>` at the end of a line for the blinking ▼ that asks for the next one. Max width 560 px; text is `pixel-16-text`.

Do: one or two sentences per page of dialog; end with ▼ when there is more. Don't: put forms or long prose in it — use a Box.
