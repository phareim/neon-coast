# Banner

The area banner: a place name in white pixel letters with a pink shadow, between a cyan line above and a pink line below.

Markup: `<span class="nc-banner">The Neon Coast</span>` (inline-block, `pixel-24`). Use it for the name of a place, a chapter or a screen — once, at the top. On canvas, `drawBanner(g, text, cx, y, alpha)` draws the same thing.

Don't: use it for buttons or for more than a few words.
