# Badge

A small solid tag: one or two pixel words on the edge colour, letters in `nc-ink`.

Markup: `<span class="nc-badge">New</span>`. Variants: `--pink` (you), `--gold` (#1, prizes), `--lime` (online, done), `--violet`, `--red`, `--quiet` (parked, off), `--outline` (letters in the colour on a dark surface).

Don't: use a badge as a button.
