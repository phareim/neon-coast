Start

Two lines in the <head>, one class on the <body>. Plain HTML inside class="nc" takes the look — headings, links, lists, buttons, forms, tables — and the .nc-* classes add the rest. The script is only needed for the canvas kit, <nc-scene> and <nc-sprite>.

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/phareim/neon-coast@master/dist/neon-coast.css">
<script type="module" src="https://cdn.jsdelivr.net/gh/phareim/neon-coast@master/dist/neon-coast.js"></script>

<body class="nc">
  <h1>Hello, coast</h1>
  <div class="nc-box">A dialog box.</div>
  <button>▶ Start</button>
</body>

The rules

  • Pixel letters at 8 px steps only: 16, 24, 32, 48, 64.
  • Edges are one unit (2 px) with notched corners. No rounded corners, no soft shadows — only the hard drop and the neon glow.
  • Cyan is the interface, pink is the call to action (and you), gold is treasure.
  • Pixel letters for the interface, Space Grotesk for prose, Space Mono for code and typing.
  • Things blink in steps; they never slide or fade. Backgrounds may move, chrome does not.

Scenery

<nc-scene> paints the coast at dusk on a canvas — stars that twinkle, a swell, palms in the wind — lit by the stage's light map and finished with bloom, scanlines and a vignette. It stops when off screen and stands still for people who ask for reduced motion.

<nc-scene scene="coast"></nc-scene>               <!-- 2:1 unless you size it -->
<nc-scene scene="town" fixed></nc-scene>          <!-- behind the whole page -->
<nc-scene scene="hills" pixels="120" still bare></nc-scene>

Canvas

The same look for games. Draw into a small logical buffer, ask for lights, and the stage scales it by a whole number, lights it, blooms it and lays the HUD on top. Sprites, the 5×7 font and the scenery painters all work in logical pixels.

import { createPixelStage, sprite, SPRITES, drawText, drawHearts, drawMeter,
         paintSky, paintSun, paintSea, drawStars, DUSK } from 'neon-coast'

const stage = createPixelStage(canvas, { minH: 120 })
stage.resize(canvas.clientWidth, canvas.clientHeight)

function frame(ms) {
  const t = ms / 1000, g = stage.begin(), { vw, vh } = stage
  paintSky(g, vw, 70)
  drawStars(g, vw, 64, t)
  g.drawImage(sunLayer, 0, 0)          // paintSun() once into its own canvas
  stage.emitImage(sunLayer)            // …which the light map leaves at full brightness
  paintSea(g, 0, vw, 70, vh, { sunX: vw / 2, time: t })
  g.drawImage(sprite(BOAT), 40 + Math.sin(t) * 20, 86)
  stage.light(vw / 2, 60, 70, DUSK.sun3, 0.5)
  drawHearts(stage.hud, 4, 4, 5, 6)
  drawText(stage.hud, 'SCORE 004200', 4, 14, '#2ff3ff', '#0b0616')
  stage.present({ ambient: '#b0a4dc' })
  requestAnimationFrame(frame)
}
requestAnimationFrame(frame)

The bands

Each window's gradient is the game's, a new colour wherever the five-bit value of a channel steps: hard stops, never a smooth CSS gradient. The CSS ramps start where every letter on them passes WCAG AA.

Letters

Neon Pixel 16: twelve-pixel capitals on a fourteen-pixel line, proportional, uppercase. One font pixel is a fourteenth of the size, so it is crisp at 14, 28, 42 and 56 px only. The last eleven glyphs (▶ ◀ ▲ ▼ ■ | [ ] @ ❚ ♪) are in the webfont only.

Sprites and the coast

<nc-sprite look="16"> takes 8-bit art up to twice the pixels with EPX and lets its dark outlines take the colour they hold (selout). <nc-scene look="16"> paints the coast at twice the pixels: the sky in knitted bands, the sun in its halo, clouds and ridges sliding at their own speeds, a sea that glints.
